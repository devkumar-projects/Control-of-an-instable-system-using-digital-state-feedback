# Twin-Rotor Helicopter: Integral State-Feedback and LQR MATLAB/Simulink Tools

MATLAB/Simulink research software for identification and integral state-feedback/LQR control of a laboratory twin-rotor helicopter. This source component contains controller scripts and authored Simulink models; the historical report distinguishes simulation and dSPACE experiments. No new hardware rerun or performance benchmark is claimed.
